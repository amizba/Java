# Agenda de Contactos en Java con Swing

Aplicación de escritorio desarrollada en Java utilizando Swing para gestionar una agenda de contactos de manera sencilla. Permite agregar, eliminar y visualizar contactos con nombre, teléfono y correo electrónico.

## Características

- Interfaz gráfica intuitiva.
- Añadir nuevos contactos con nombre, teléfono y correo.
- Eliminar contactos por nombre.
- Visualización clara de todos los contactos añadidos.
- Campos de entrada y botones de acción accesibles.

## Requisitos

- JDK 8 o superior
- IDE como Eclipse, IntelliJ IDEA o NetBeans (opcional)

## Cómo ejecutar

1. Clona el repositorio o copia el código fuente.
2. Abre el proyecto en tu entorno de desarrollo Java.
3. Compila y ejecuta el archivo `AgendaContactos.java`.
4. Aparecerá una ventana con la interfaz de la agenda.

## Estructura del código

- **Clase principal**: `AgendaContactos`  
- **Componentes clave**:
  - `JTextField`: para ingresar datos del contacto.
  - `JTextArea`: para visualizar los contactos añadidos.
  - `ArrayList<Contacto>`: para almacenar los contactos temporalmente.
- **Acciones**:
  - `Agregar`: Añade un contacto a la lista.
  - `Eliminar`: Elimina un contacto por nombre.
  - `Limpiar`: Vacía los campos de entrada.
