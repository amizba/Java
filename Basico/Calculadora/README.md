# Calculadora Gráfica en Java

**Autor:** Amparo Izquierdo Bañez  
**Email:** amizba@gmail.com

## 📋 Descripción

Este proyecto implementa una **calculadora gráfica básica** en Java con interfaz creada mediante la biblioteca Swing. Permite realizar operaciones aritméticas básicas como suma, resta, multiplicación y división, así como el uso de **paréntesis** para establecer el orden de las operaciones.

## 🖥️ Características

- Interfaz gráfica sencilla y clara.
- Soporte para las siguientes operaciones:
  - Suma `+`
  - Resta `-`
  - Multiplicación `*`
  - División `/`
  - Agrupación con paréntesis `()`
- Botones funcionales:
  - `C`: Borrar toda la entrada.
  - `⌫`: Borrar último carácter.
  - `=`: Evaluar expresión.

## 🛠️ Requisitos

- Java JDK 8 o superior
- IDE recomendado: Eclipse, IntelliJ IDEA, NetBeans (o puedes usar compilación desde terminal)
